# ComputIQ – Computing Aptitude and Logical Reasoning Assessment System

## About the Project
ComputIQ is a C++ console-based assessment system designed to test computing aptitude, logical reasoning, and mathematical aptitude.

## Features
- Student name and roll number input
- Computing aptitude quiz
- Logical reasoning quiz
- Mathematical aptitude quiz
- Full assessment mode
- Automatic score and percentage calculation
- Performance feedback
- Save assessment results in a text file

## Technologies Used
- C++
- Standard C++ Library
- File Handling

## How to Run
1. Install a C++ compiler such as GCC.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Compile the program:

   `g++ main.cpp -o computiq`

5. Run the program:

   Windows: `computiq.exe`

   Linux/macOS: `./computiq`
